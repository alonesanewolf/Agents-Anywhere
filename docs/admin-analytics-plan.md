# 管理页与 Analytics 设计简记

记录日期：2026-10-08。状态：讨论结论，尚未实现；具体字段、契约和迁移后续细化。

## 目标与采集范围

- 新增专用 analytics 表，在业务操作及执行结果的确认位置埋点。管理页从统计数据查询，避免反复扫描 Timeline 或在读取 dashboard 时生成统计数据。
- 主要记录用户发起的行为及其执行情况，包括管理员操作。高频行为不记录，也不另做高频行为聚合。
- 不记录心跳、轮询、输出增量、终端按键与输出、连续滚动、后台预加载、重复状态上报等。
- 保留 Connector 连接、断联、重连和 Runtime 启停、异常退出等关键生命周期变化，解释用户操作结果；自动变化不计入主动操作次数或用户活跃。
- 公告仅保留发布／更新记录及每个版本的查看人数。同一用户查看同一版本只记一次；后台拉取不算查看。

## 操作及指标

| 范围 | 记录内容与主要指标 |
| --- | --- |
| 账号与配对 | 注册、登录、重置密码、绑定账号、设备配对；操作次数、人数、结果、失败原因，适用时记录耗时 |
| Session 查看 | 主动打开、首屏可用、打开失败、主动加载历史；查看人数、打开次数、不同会话数、成功率、首屏与历史加载耗时 |
| 会话管理 | 新建与导入／发现已有会话分别计数；接管、归档、恢复及其结果 |
| 消息与运行 | 消息提交、接受，运行开始、首次有效输出、完成、失败、中断、结果未知；次数、人数、结果比例、等待与执行耗时 |
| 审批与控制 | 批准、拒绝、输入响应；interrupt、steer、compact 等有效命令、手动同步；接受与最终结果、耗时，覆盖允许时记录审批等待时间 |
| Connector | 配对与连接结果、连接耗时、连接次数、断联原因、重连次数、在线时长；当前在线状态单独展示 |
| Runtime | 配置、启动、停止、切换、模型／权限选项变更及实际结果；类型、版本、最近确认状态、操作次数与耗时 |
| 项目、文件、终端、Shell、分享 | 用户主动操作及结果；使用人数、次数，适用时记录传输大小、耗时和退出码；后续逐步接入 |
| 管理变更 | 用户、角色、权限、服务配置与公告变更；操作者、对象、实际生效内容、时间、结果 |

Session 查看是首期核心行为。一次进入会话产生一个打开操作，metadata、snapshot、timeline 等请求关联到同一次操作；刷新、推送和重连不增加查看次数。用户离开后再次进入算新操作。查看与标记已读分开，不声称用户已读完内容。

活跃用户按主动查看或执行操作去重；查看活跃与操作活跃可分别展示。“只查看”也是有效使用，不直接解释为流失。

## 数据口径

- 同一操作通过 `operation_id` 关联请求、接受和终态；执行尝试与用户操作分开，重试不重复增加操作次数。事件采用稳定标识去重。
- 按实际能力记录 requested、accepted、completed、rejected、failed、cancelled／interrupted、unknown 等阶段；接口返回成功不直接等于执行完成。
- 消息与运行分别统计；运行关联明确的执行标识，不能由一条 assistant 消息结束推断整个运行完成。
- 无法确认结果时保留 unknown，后续确认后补充终态。等待接口超时不直接等于任务执行超时。
- 批量操作记录一次操作及影响数量，需要时补充各对象结果。主动历史加载的一组底层分页请求归到同一次操作。
- 耗时附在用户操作上；不另建每次后台请求的统计。跨端时间不可直接相减作为精确耗时。
- 保存必要的用户、对象、客户端／版本、Runtime、来源、时间、结果及数值；不保存消息正文、命令全文、文件内容、审批输入、密码或密钥。
- 当前在线／运行状态以实时状态来源为准，历史 analytics 不能证明当前在线。旧状态注明最后确认时间；不完整的生命周期注明推断或未知。
- 比例明确分母，未知结果单独展示。范围内人数／会话数按集合去重，不能相加每日去重数；注明时区、数据更新时间与覆盖范围。
- 历史基线、补录与真实新增分开；缺失的数据不伪装成完整历史。管理员审计需要独立的访问权限与保留策略。

## 管理页组织

统一采用数字卡片 → 趋势图 → 分类表格 → 记录详情。默认最近 7 天，支持今天、30 天、自定义范围；当前状态与范围内统计分别展示。适用指标按用户、客户端、版本、Runtime 筛选，耗时展示中位数和 P95。

1. **总览**：活跃／新增用户、会话查看、已接受消息、运行结果、当前 Connector／Runtime 状态；使用与耗时趋势、主要失败原因、关键异常及近期管理变更。
2. **会话与操作**：查看、消息与运行、审批、控制及其他操作的使用量、结果、耗时；查看用户中发送／响应的比例及只查看用户数。
3. **Connector 与 Runtime**：设备与 Runtime 列表、当前状态、版本、稳定性统计、关键生命周期记录。
4. **用户**：注册与最近主动使用时间、范围内会话查看与消息数、关联设备；用户详情展示使用趋势和操作结果。
5. **配置与管理记录**：可配置功能、变更记录；公告发布状态、更新时间与每个版本的查看人数。

首期优先总览、Session 查看与执行、审批与控制、Connector／Runtime、管理记录；项目、文件、终端、Shell、分享随后补齐。本记录不授权实现、部署或其他运行操作。
